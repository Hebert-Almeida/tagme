    Conecte sua biblioteca Zotero

    Cole sua chave de API do Zotero e seu User ID para acessarmos sua biblioteca. Suas credenciais ficam apenas na memória e são apagadas ao fechar a aba.

    Não tem uma chave? Crie sua chave de API no Zotero — marque Read/Write nas permissões de biblioteca.

    Seu ID aparece na página de Chaves de API do Zotero , logo acima da lista de chaves.

    Guarde sua API Key e User ID em um arquivo de texto no seu computador — você precisará deles toda vez que abrir o TagMe.
